# Эксперимент: лесная экосистема с решениями Kev

Поручение Сергея, 28.09.2026: смоделировать лесную экосистему — хищников, травоядных и птиц. Kev принимает тактические решения: выбирает паттерн поведения и реакцию на событие, а исполняет выбранное простая механика. Проверяем, насколько решения осмысленны и успевают ли они в реальном времени. Игра только для себя, поэтому всё запускается на компьютере Сергея. Основа — [разбор Kev](../inbox/2026-09-27-kev-npc-research.md).

Порядок, как в разобранном видео: **сначала модель на данных, потом движок.** Экосистема сначала живёт в симуляции на Python без графики. В Godot она переносится, только когда поведение и нагрузка понятны.

## Гипотезы

| ID | Проверяем |
|---|---|
| H1 | Kev-0.8B на RTX 5070 Ti отвечает на тактический вопрос животного быстрее реакции живого зверя (0,2–0,5 с), в том числе при всплеске событий у стаи |
| H2 | Без дообучения решения в явных ситуациях разумны: голодная — пасётся, видит волка рядом — бежит |
| H3 | Характер и физические данные в state меняют выбор: смелая и трусливая косуля в одной ситуации ведут себя по-разному, но предсказуемо |
| H4 | Из решений отдельных животных складывается живая экосистема: численность колеблется, а не вымирает; стаи держатся, лидеры сменяются |
| H5 | Дообучение на данных самой симуляции заметно улучшает H2–H4 |

Kev-4B требует около 17 ГБ и в 16 ГБ не помещается, поэтому работаем с 0.8B.

## Устройство симуляции

**Мир** — лес 500 × 500 м в 2D, такт 10 Гц, смена дня и ночи. Карты:
- плотность леса — укрытие и видимость;
- трава и кустарник — отрастают;
- ручей и водопой;
- норы и лёжки.

**Виды:**

| Вид | Роль | Социальность |
|---|---|---|
| Косуля | Травоядное, чуткое | Небольшие группы |
| Кабан | Всеядное, может дать отпор | Стадо с вожаком-самкой |
| Заяц | Замирает или убегает | Одиночка |
| Волк | Загонщик | Стая, лидер |
| Рысь | Засадный хищник | Одиночка |
| Лиса | Мелкая добыча, падаль | Одиночка |
| Сойка | Тревожный крик слышат все | Одиночка |
| Ворон | Падаль, летит за волками | Пары |

**Животное** — это:
- тело: голод, жажда, усталость, здоровье, возраст, пол;
- физика: скорость, выносливость, сила, дальность зрения, слуха и нюха;
- характер: смелость, любопытство, общительность, властность, бдительность;
- память: где вода и еда, где и когда видели хищника;
- социальное: группа, ранг, лидер;
- восприятие: кто рядом, на каком расстоянии, в какой стороне, насколько виден, движется ли;
- события за последние секунды.

### Три слоя решений

| Слой | Частота | Кто решает | Пример |
|---|---|---|---|
| Рефлекс | Каждый такт | Механика | Хищник в прыжке ближе 5 м — бегство без вопросов к модели |
| Реакция | По событию | Kev | Движение между деревьями: пастись дальше, замереть и смотреть, крикнуть группе, убежать, подойти посмотреть |
| Паттерн | Когда паттерн закончен, потребность перешла порог или раз в 5–20 с | Kev | Спать, идти к ручью, пастись, искать укрытие, идти за группой, разведывать |

Хищнику Kev выбирает ещё и цель из списка видимых добычи — pointer head как раз для выбора из списка. После этого он решает: красться, гнать или бросить.

Социальные решения — тоже вопросы к Kev: примкнуть к группе, бросить вызов лидеру, уступить. Исход стычки считает механика: сила, здоровье, случайность.

Механика исполняет выбранное:
- движение к цели и от угрозы, стайное движение;
- расход и восполнение энергии;
- погоня с учётом скорости и выносливости;
- обнаружение с учётом леса и расстояния;
- исход охоты.

Решение приходит асинхронно. Пока оно считается, животное продолжает прежний паттерн.

**Вопрос к Kev — плотный state.** Не проза, 100–300 токенов, 2–4 вопроса за раз: паттерн (`choice`), тревога группе (`noul`), цель (выбор из списка). Выбор семплируется по распределению, а не берётся максимум.

### Решатели для сравнения

Один и тот же мир с тем же seed гоняется с разными решателями:
- **случайный** — нижняя граница;
- **ручной utility AI** — базовая линия и заодно проверка механики;
- **Kev-0.8B** без дообучения;
- **Kev-0.8B + LoRA**.

## Замеры

- **Скорость:**
  - задержка решения p50/p95/p99 с очередью;
  - решений в секунду;
  - доля реакций, опоздавших к сроку — 0,3 с симуляционного времени;
  - видеопамять;
  - то же при запущенной игре.
- **Разумность:**
  - набор из ~60 ситуаций на 5 видов с ожидаемыми ответами (составляет Саня, спорные решает Сергей);
  - монотонность: растёт голод — растёт доля «пастись»;
  - одинаковый state даёт одинаковое распределение.
- **Характер:** расхождение распределений у разных характеров в одной ситуации при устойчивом выборе одного характера.
- **Экосистема:**
  - кривые численности;
  - смерти от голода и от хищников;
  - успешность охоты;
  - сплочённость групп, смены лидеров.
- **Зрелище:** просмотр записи. Симуляция пишет повтор в JSONL, простой HTML-просмотрщик показывает карту сверху, значки животных, текущий паттерн и последнее решение с вероятностями.

## Сервер Kev

- Установка — в Ubuntu (WSL2), `~/ml/kev`, через `uv sync --extra serve`. Шаги установки Сергей получил в чате 28.09.2026.
- Запуск: `uv run --extra serve python -m kev.serve --run jaredpalmer/kev-0.8b --port 8009`. Из Windows сервер доступен как `localhost:8009`.
- Запрос: `POST /v1/systemone` с JSON `{"state": "...", "questions": {...}}`. Вопрос `choice` задаёт варианты в `criteria` — имя варианта и описание; `noul` — вероятность «да».
- Ответ: `answers.<вопрос>.probabilities` — распределение по вариантам, `choice` — самый вероятный вариант; для `noul` — `answers.<вопрос>.noul`. `latency_ms` — время модели.

## Шаги

| Шаг | Что | Критерий успеха |
|---|---|---|
| E0 | Установка Kev в Ubuntu (WSL2), замер: 1/8/32/64 одновременных запроса, state 100/200/400 токенов, 1/3/6 вопросов; потом то же с запущенной игрой | Проверка H1: 0.8B p95 ≤ 50 мс при 8 запросах; видеопамять ≤ 4 ГБ; игра не проседает ниже 60 FPS |
| E1 | Набор ситуаций, подбор формата state (YAML против JSON), замер качества без дообучения | Проверка H2 и H3: ≥ 80% совпадений на явных случаях |
| E2 | Симуляция с ручным utility AI, быстрее реального времени | Механика отлажена, экосистема живёт хотя бы 30 игровых дней |
| E3 | Тот же мир на Kev, ускоренно, батчами | Сравнение с E2 по замерам экосистемы |
| E4 | Реальное время: 50/100/200 животных, всплеск — стая волков выходит к 20 косулям | Доля опоздавших реакций; где нужен рефлекс |
| E5 | Стаи, стада, лидерство | Проверка H4 |
| E6 | Датасет из состояний симуляции, разметка большой моделью, LoRA | Проверка H5 |
| E7 | Перенос в Godot: животные в воксельном лесу, тот же сервер | Решает Сергей по итогам E0–E6 |

Симуляция — Python в `sim/ecosystem/` этого репозитория, запускается в WSL рядом с сервером Kev. Её технические тесты идут с синтетическим решателем, без модели ([правила тестирования](../testing-rules.md)).

## Решения Сергея

- Kev установлен в Ubuntu (WSL2), тестовый запрос отвечает: первый — больше 200 мс, дальше 100–120 мс с дороги, изредка около 10 мс.
- Начинаем с косули, зайца, волка и сойки, потом добавляем виды.
- Точность решений пока не главное: при необходимости модель дообучим. Главное — насколько Kev помогает сделать жизнь экосистемы не шаблонной, чтобы каждое животное делало свой выбор, и какой ценой по нагрузке и скорости.
- Модель локальная, её можно гонять сколько угодно: пробуем разные варианты моделирования, масштаб до десятков тысяч животных и ускорение времени.
