# Симуляция лесной экосистемы: устройство

Симуляция к [эксперименту с Kev](kev-ecosystem.md): Python-пакет `eco` в `sim/ecosystem/`, без графики. Механика векторная (numpy, struct of arrays по особям, соседи — `scipy.spatial.cKDTree`), решения принимают сменные решатели, в том числе Kev.

## Запуск

Код запускается в WSL (Ubuntu 24.04), диск C там не подключён. Из Git Bash код копируется в `~/ml/eco` (`sim/sync.sh`) или в свою папку: `cp -r sim/ecosystem/. "//wsl.localhost/Ubuntu-24.04/home/nikservik/ml/<папка>/"`. В папке: `uv sync`, затем:

```
uv run pytest                                   # технические тесты, меньше секунды, без сети
uv run python -m eco.run --variant V0 --animals 1000 --days 30
uv run python -m eco.run --variant V1 --oracle kev --animals 200 --days 1 --time batched
uv run python -m eco.run --variant V1 --oracle kev --animals 100 --days 0.1 --time realtime
uv run python -m eco.run --variant V4 --oracle kev --animals 2000 --days 1 --observer 300,300
uv run python -m eco.run --variant V0 --animals 300 --days 1 --record ~/ml/out/rec.jsonl
```

| Ключ | Значение |
|---|---|
| `--variant` | `random`, `V0`–`V5` (ниже) |
| `--oracle` | `mock` — синтетический оракул, `kev` — сервер `localhost:8009`; для `random` и `V0` не нужен |
| `--animals`, `--days`, `--seed` | начальная численность, игровые дни, зерно мира и решений |
| `--time` | `batched` — такт ждёт все ответы; `realtime` — такт по стене часов 10 Гц, ответ применяется, когда пришёл |
| `--species` | `base` (косуля, заяц, волк, сойка), `all` или список ключей: `roe,hare,wolf,jay,boar,lynx,fox,raven,mouse,owl,badger` |
| `--record` | JSONL для просмотрщика; `--record-every N` — кадр раз в N тактов (по умолчанию 10, то есть раз в секунду) |
| `--observer x,y` | точка камеры для V4; по умолчанию центр мира |
| `--size` | сторона мира, м; по умолчанию 500 м на 1000 животных, площадь растёт пропорционально численности |
| `--day-seconds`, `--year-days` | длина игровых суток (600 с) и года (12 суток, сезон — 3 суток) |
| `--productivity` | множитель ёмкости пищи в клетке |
| `--mock-latency` | задержка MockOracle, с |
| `--run`, `--out` | имя прогона и папка итогов; итог — `<out>/<run>/report.json`, по умолчанию `~/ml/out/` |

Просмотрщик — `sim/ecosystem/viewer.html`: открыть в браузере и выбрать файл записи (или `viewer.html?src=<url>` при раздаче по http). Карта сверху: лес, вода, норы, значки видов, у вожаков жёлтое кольцо, подпись паттерна при приближении. Клик по животному — последнее решение: вероятности по каждому вопросу, выбранное, источник (v0, oracle, cache, policy, follow, far_v0). Перемотка ползунком и стрелками, пробел — проигрывание. Данные записи в git не кладутся.

## Мир и время

- Такт 0,1 с. Сутки — 600 с, год — 12 суток; прогон начинается утром первого дня весны. Свет задаёт видимость; ночь — свет ниже 0,1.
- Лес — сглаженный шум 0–1; вода — ручей через весь мир и пруды (один на 250 × 250 м). Каждая особь с рождения знает ближайшую к месту появления воду и запоминает воду, увиденную позже.
- Трава (открытые места) и кустарник (опушки) отрастают к ёмкости клетки: весна 0,6/0,4, лето 0,5/0,3, осень 0,2/0,15, зима 0,02 доли недостающего в сутки. Желуди падают осенью под дубами (густой лес) и медленно исчезают; ягоды растут летом и осенью.
- Падаль — туша добычи в клетке; портится (летом быстрее). Хищники и падальщики едят её той же механикой, что траву.
- Норы и лёжки — точки в лесу (одна на 50 × 50 м); у норных видов ближайшая нора — дом для отдыха, детёныши наследуют дом матери.

## Особь

- Тело: голод, жажда, усталость, здоровье, выносливость, возраст, пол, беременность.
- Характер (смелость, любопытство, общительность, властность, бдительность, 0–1) и физика (множители скорости, выносливости, силы, чувств): у детёныша — среднее родителей плюс разброс 0,08. Признаки отца запоминаются при зачатии.
- Память: вода, сытное место, где и когда видела хищника.
- Социальное: группа, ранг (по силе × здоровью × властности), вожак; детёныш до половины взросления ходит за матерью.
- Восприятие (раз в 0,3 с): ближайшая угроза (кто, дистанция, сторона, движется ли, увидена, услышана или учуяна), до 4 видимых жертв у хищника, ближайший сородич. Видимость падает с лесом, ночью, у затаившихся, неподвижных и мелких; бег слышен, у рыси и совы — бесшумный.
- События последних секунд: увидела хищника (после 10 с без него), услышала сойку, тревога группы, увидела добычу (голодный хищник).

## Жизненный цикл

- Голод растёт на 0,5 в сутки (у хищников 0,4), жажда — по виду; при голоде или жажде ≥ 0,95 падает здоровье. Сытая особь восстанавливается.
- Зачатие: взрослая самка в сезон гона, здоровье > 0,5, голод < 0,7, в той же клетке 100 × 100 м есть взрослый самец её вида; не чаще числа выводков в год. В стае волков рожает только вожак или первая по рангу. У мыши, зайца, сойки и ворона зачатие гасит плотность своего вида в клетке (предел на гектар). В начале прогона самки видов с гоном до весны уже беременны (у волков — одна на стаю).
- Роды в срок: выводок в пределах вида, детёныши медленнее и слабее, у стадных видов входят в группу матери.
- Смерть и её причина: `old_age` (индивидуальный срок жизни), `starvation`, `thirst`, `predator:<вид>`, `wounds` (раны от неудачной атаки), `fight` (стычка за лидерство), `other` (фоновая смертность — болезни, погода и мелкие хищники, которых нет в модели).

## Паттерны и механика

Общий список паттернов: `rest`, `graze`, `drink`, `follow`, `flee`, `hide`, `explore`, `hunt`, `scavenge`, `patrol`, `investigate`, `ambush`; каждому виду доступно своё подмножество. Механика исполняет выбранное:

- `graze` — идти к пище рациона по 24 точкам на 8, 25 и 60 м, есть на месте; скудно вокруг — к запомненному сытному месту или прямо вперёд.
- `drink` — к запомненной воде; `rest` — в нору или в густой лес; `hide` — замереть, видимость ×0,35; `explore` — блуждание.
- `follow` — к вожаку (детёнышу — к матери, ворону — к ближайшему волку); рядом с вожаком особь повторяет его занятие: ест, пьёт, отдыхает, бежит, охотится на ту же цель.
- `flee` — бег от угрозы с разбросом направления; выносливость кончилась — скорость 0,45 от бега.
- `hunt` — скрадывание шагом до дистанции броска, затем погоня; бросает, если цель не видна и не учуяна 4 с, выносливость кончилась, прошло 120 с. Поимка — ближе 1,5 м; исход — сила хищников рядом (стая складывается) против силы жертвы (детёныш ×0,3) и случайность. Удача — туша в падаль, охотники переходят к `scavenge`; неудача — жертва ранена, хищник бросает. Взлетевшую птицу наземный хищник не ловит.
- `ambush` (рысь) — в густом лесу ждать; при голоде выше 0,3 рысь бросается на видимую жертву ближе 1,5 дистанции броска.
- `scavenge` — к падали по запаху (грубая сетка 25 м, у птиц дальше), рядом — к туше.
- `patrol` — вожак стаи обходит территорию; центры территорий соседних стай расходятся.
- `investigate` — подойти к источнику события.

Группы (раз в секунду): вожак погиб — вожаком становится сильнейший; вызов вожаку — исход по силе × здоровью × властности со случайностью, проигравший ранен, не чаще раза в 120 с на группу; отставший дальше 150 м уходит; группа больше предела делится; стада одного вида с вожаками ближе 20 м сливаются, если вместе не больше предела; стаи не сливаются; молодые волки низкого ранга расселяются; одиночка, решивший примкнуть, входит в группу соседа или создаёт пару.

Межвидовое: крик сойки (решение «тревога») слышат все особи в радиусе 80 м — событие и реакция; вороны следуют за ближайшим волком и садятся на падаль; лиса и барсук едят падаль.

## Решения

Три слоя:

| Слой | Когда | Кто |
|---|---|---|
| Рефлекс | каждый такт | механика: хищник в погоне ближе 5 м или любой ближе 2 м — бегство без вопроса, 3 с запрета других решений |
| Реакция | новое событие | решатель: `continue`, `freeze`, `flee`, `investigate` у добычи; `continue`, `stalk`, `investigate` у хищника |
| Паттерн | паттерн закончен, потребность перешла порог (голод или жажда > 0,6, усталость > 0,8; не чаще раза в 3 с) или прошло 5–20 с | решатель: выбор из паттернов вида |

К вопросу паттерна или реакции добавляются: цель хищника (выбор из видимых жертв), тревога (сойка — на весь лес, член группы — своим), примкнуть (одиночка стадного вида рядом с сородичем), вызвать вожака (член группы). Всего 1–4 вопроса. Варианты — короткие английские описания. Выбор всегда семплируется из распределения.

Решение асинхронное: пока ответ не пришёл, особь держит прежний паттерн, новых запросов того же вида не шлёт. Ответ для погибшей особи или занятого другой особью места отбрасывается.

State для оракула — плотный текст 100–300 токенов: вид, пол, возраст, потребности, характер, физика, время суток и сезон, лес вокруг, текущее занятие и его длительность, группа и вожак, угроза, жертвы, туша рядом, ближайший сородич, вода, память о хищнике, события последних 5 с.

### Решатели

| Вариант | Как решает |
|---|---|
| `random` | равномерно из допустимого — нижняя граница |
| `V0` | ручной utility AI, векторно: полезности паттернов и реакций из потребностей, характера, угроз и надбавки за незаконченное занятие; softmax (температура 0,12 и 0,15) и семпл |
| `V1` | каждый запрос — вопрос оракулу |
| `V2` | вожак, одиночки и все при реакциях спрашивают оракула; запрос паттерна члена группы и детёныша — сразу `follow` |
| `V3` | кэш по огрублённому state (вид, вид запроса, голод, жажда, усталость по 3 уровня, угроза нет/далеко/близко, роль, ночь, смелость по 3 уровня, тревога, видна ли добыча, одиночка рядом с сородичем, детёныш): попадание — семпл из сохранённого ответа, промах — оракул |
| `V4` | внимание по расстоянию до наблюдателя: ближе 60 м — оракул; 60–200 м — кэш V3, промах — оракул, интервал решений ×2; дальше — кэш, промах — V0, интервал ×4 |
| `V5` | личная политика: оракул раз в 120 с (и при первом запросе) отвечает на 4 вопроса — распределение паттернов в ситуациях «спокойно», «голод или жажда», «опасность», «ночь»; между обновлениями особь семплирует из распределения своей текущей ситуации |

V1–V5 работают поверх оракула: `KevOracle` (через `eco/kev.py`) или `MockOracle` — распределения из разобранного state и искусственная задержка. Цель хищника в ответах из кэша и политики, тревога в V5 — по правилу V0.

Режимы времени: `batched` — такт ждёт все ответы, задержка на ход мира не влияет (E3); `realtime` — такт идёт по стене часов 10 Гц, ответ применяется, когда пришёл; реакция, применённая позже 0,3 с симуляционного времени после запроса, считается опоздавшей (E4).

## Замеры

Каждый прогон пишет `report.json`:
- скорость: игровых дней за минуту стены, тактов в секунду; решений запрошено и обслужено в секунду симуляции и стены, по источникам; вопросов к оракулу в секунду; задержки модели и с дороги p50/p95/p99; задержка реакций в симуляционном времени и доля опоздавших (только `realtime`); загрузка GPU и видеопамять при `--oracle kev`;
- экосистема: численность по видам раз в игровой час, рождения, смерти по причинам, охоты (начатые погони) и добычи, события и тревоги, рефлексы;
- группы: среднее число и размер, распавшиеся и медиана их жизни, смены вожака по причинам, вызовы, присоединения, слияния, расколы;
- выбор: счёт выбранных паттернов по видам, энтропия выбора и средняя энтропия распределений, JS-дивергенция распределений паттернов у робких (смелость < 0,33) и смелых (> 0,67) в одной огрублённой ситуации (голод, жажда, угроза, ночь), взвешенная по ситуациям, где у обоих не меньше 20 решений;
- для V3/V4 — доля попаданий в кэш, для V4 — число решений по зонам внимания, для V5 — число решений из политики.

## Технические тесты

`sim/ecosystem/tests/`, pytest, без сети, меньше секунды: голод и еда, питьё, смерти по причинам, зачатие, роды и наследование, отрастание; охота и туша, отказ от погони, рефлекс; новый вожак, вызов, присоединение, раскол и слияние; тревога сойки для всех видов рядом, ворон за волком, лиса на падали; V0, семплирование, удержание паттерна до ответа и счёт опоздавшей реакции, батч-режим, V2–V5; решатель Kev с подменённым HTTP-транспортом; JS-дивергенция; запись JSONL.

**50 000 животных** (мир 3,5 × 3,5 км): 4 вида — 35 тактов в секунду (3,5× быстрее реального времени), 0,35 игрового дня за минуту; все виды — 33 такта, 0,33 дня за минуту. Решений V0 — около 7000 в секунду симуляции: столько вопросов получил бы оракул в V1.

Устойчивость держится на правилах V0: хищник начинает охоту и выбирает `stalk` только при голоде выше 0,4, а у туши доедает её до сытости; незаконченное занятие получает надбавку 0,3. Для Kev это значит: если он охотится сытым или бросает тушу, экосистема сорвётся — это видно по численности и причинам смерти.

JS-дивергенция робких и смелых у V0 мала (0,002–0,04 бита): в ручных полезностях смелость влияет только на бегство, укрытие и реакции.

## Ограничения

- Медведя нет. Сценарий E4 «стая волков выходит к 20 косулям» отдельной командой не собран: его ставят через `Sim.add` и `--time realtime`.
- Kev в прогонах не вызывался: решатели V1–V5 проверены с MockOracle и подменённым HTTP-транспортом.
- Мир сжат: плотности животных на порядки выше природных, поэтому доли видов, пределы плотности и фоновая смертность подобраны под устойчивость, а не под полевые данные.
