# Рельеф

Рельеф — гладкие воксели на [godot_voxel](https://github.com/Zylann/godot_voxel). Библиотеку выбрали потому, что игрок копает ([TER](../features/terrain.md)). Обычный рельеф по карте высот не даёт ни ям глубже поверхности, ни туннелей, ни пещер.

## Основа

- Библиотека — godot_voxel 1.7x: GDExtension-сборка из официальных Releases (`GodotVoxelExtension.zip`). Встаёт в обычный Godot 4.7.2 без пересборки. Контрольных сумм у релиза нет; автор предупреждает, что GDExtension-сборка проверена слабее модульной.
- Узел `VoxelLodTerrain`, сетка Transvoxel, LOD. Генератор `VoxelGeneratorGraph`, граф собирается кодом.
- Изменения — через `VoxelToolLodTerrain.do_sphere`. Хранение — `VoxelStreamSQLite`, сохраняются только изменённые блоки (`save_modified_blocks`).

## Что показал пробный прототип

Проверено на RTX 5070 Ti (Vulkan Forward+), в сцене без растительности и объектов. Участок 1024 × 256 × 1024 м, 6 уровней LOD.

| Замер | Результат |
|---|---|
| Генерация | Область у героя готова за 0,45–0,66 с, весь участок — за 0,6–0,7 с |
| FPS вдаль | 1669 в 1080p, 1352 в 1440p; p99 кадра — около 1 мс |
| FPS при копании в каждом кадре | 323–351; p99 кадра — около 6,4 мс |
| Память | Статическая около 160 МБ; видео 166–211 МБ |
| Старт без окна | Расширение добавляет около 2 мс |
| Сохранение | Файл после одной ямы — 160 КБ. Рост при многих правках не мерили |

## Ограничения, которые учитывает реализация

- Материал рельефа нужно писать под переходы LOD (`u_transition_mask`) — это касается любого шейдера рельефа.
- Материал по одному уклону красит пол пещер травой. Для [TER-1.2](../features/terrain.md) нужна покраска по вокселям: texture channel в `VoxelTool` и режим текстурирования меша.
- Коллизия есть только в LOD0 рядом с наблюдателем. Объектам и существам вдали от героя нужна своя логика.
- При вокселе 1 м и шаре 1,5 м края ям гранёные.
- Библиотеку поддерживает в основном один автор. Формат сохранений связан с её версией, поэтому версию обновляем осознанно.
